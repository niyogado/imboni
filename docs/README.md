# iMBONi — Team Guide (simple)

1. Put `.clinerules` in the project root and this `docs/` folder next to it.
2. Each developer opens their file in `docs/roles/` and copies their Cline prompt.
3. Before each task, write your task at the bottom ("My task:") and paste it to Cline.
4. Read `docs/PROJECT_STRUCTURE.md` to see which folder is yours.

Golden rule: **only edit your own folder. Need something from another folder? Ask its owner.**
